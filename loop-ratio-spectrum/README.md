# loop-ratio-spectrum

Code for the analysis reported in *Loop Ratio Spectrum of Complex Networks:
A Basis-Cycle Descriptor Linking Topology to Spreading and Robustness*
(Z. Zhao, J. Li, J. Cui).

The repository contains the scripts that build the loop-basis cycle-length
distribution of a network, extract the descriptors used in the paper, run the
dynamical and structural experiments, and regenerate every figure and table.

## Layout

```
code/            analysis scripts
data/            edge lists of the eight benchmark networks (karate ... yeast)
results/         generated by the scripts (json pickles csv)
figures/         generated by the scripts
```

## Requirements

Python 3.10 or newer with numpy, scipy, networkx, pandas and matplotlib:

```
pip install -r requirements.txt
```

## Running

All scripts are run from the repository root, for example

```
python code/compute_lrs.py all
```

`compute_lrs.py` is the main pipeline and accepts the stages `core`, `pin`,
`sir`, `perc`, `null`, `tables`, `figs` or `all`.  Stage `core` is the slow one:
it computes the descriptor set and the exact cycle enumeration for the small
networks, and stage `null` performs the configuration-model rewiring.

Inputs are read from `data/` and outputs are written to `results/` and
`figures/`.  Both roots can be overridden with the environment variables
`LRS_DATA`, `LRS_RES` and `LRS_FIG` (see `code/paths.py`), which is useful when
the edge lists live on another volume.

## Scripts

| script | content |
| --- | --- |
| `paths.py` | path conventions and environment overrides |
| `lrs_common.py` | graph loading, depth-first cycle basis, LRS core descriptors |
| `compute_lrs.py` | main pipeline: descriptors, pinning, SIR, percolation, null models, tables, Figures 1-8 |
| `build_graphs.py` | downloads the eight benchmark networks and writes the edge lists in `data/` |
| `attacks.py` | percolation attack curves and summary quantities |
| `overlap_attack.py` | node loop ratio versus degree, stratified attack, threshold margin (Section 7) |
| `rewire.py` | controlled rewiring at fixed mean degree and fixed kappa/m (Section 4.1) |
| `sir_beta.py` | SIR outcome as a function of the transmission probability (Section 6) |
| `basis_families.py` | depth-first, breadth-first and minimum cycle bases compared (Section 2) |
| `min_cycle_basis.py` | minimum cycle basis substitution and its effect on the cross-network association |
| `table4_summary.py` | partial correlations of Table 4 |
| `figures.py` | Figures 3 and 5 at the width used in the manuscript |
| `bearing_mfpt.py` | MFPT bearing-state networks, descriptors, leave-one-record-out (Section 9) |
| `bearing_checks.py` | decimation control and the fixed-load comparison (Section 9) |
| `baselines_mfpt.py` | window-level amplitude baselines on the MFPT records |
| `cwru.py` | CWRU bearing-state networks and leave-one-record-out |
| `baselines_cwru.py` | window-level amplitude baselines on the CWRU records |
| `figures_bearing.py` | Figure 9 |
| `parameter_grid.py` | preset embedding-dimension / recurrence-rate grid reported in Section 9 |

The edge lists in `data/` are the largest connected components of the public
networks, relabelled `0..n-1`; `build_graphs.py` reproduces them from the
original sources.  The bearing experiments read the MFPT and CWRU recording
archives, which are not redistributed here; place them under
`data/mfpt/` and `data/cwru/` as described in `data/README.md`.

## Notes on runtime

The minimum cycle basis (Horton) is superlinear in the graph size and does not
finish within a useful time budget above about a hundred nodes, so it is
reported for the three smallest networks only.  Exact betweenness centrality on
the 4941-node power grid takes about a minute, which is why `overlap_attack.py`
reports the cost of the two point-selection strategies separately.

All random draws are seeded (`SEED = 20261008`), so repeated runs reproduce the
same numbers.
